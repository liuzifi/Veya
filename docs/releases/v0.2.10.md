# Veya v0.2.10

本版本优化了快捷面板设置中的**字体**与**字号**项，让用户能直接选择系统已安装的中文字体（如微软雅黑、等线、黑体等），并将字号操作改为更直观的步进控件，调整后即时生效。

## 字体设置：系统字体可选

- 设置页「字体」项从原来的「默认 / 等宽」两个固定芯片，改为列出当前系统**已安装且确认支持简体中文**的字体（微软雅黑、微软雅黑 UI、等线、黑体、Noto Sans SC、思源黑体等）。
- 仅列出白名单内的 CJK 字族，避免用户选到无汉字的拉丁字体导致界面变豆腐块。
- 点击字体芯片**立即生效**，无需额外「应用」按钮；所选字体会持久化到配置并在下次启动时恢复。
- 旧版本持久化的 `default` / `mono` 键会被安全映射到第一个可用的中文字体，升级后不会丢失可读性。

## 字号设置：步进控件即时反馈

- 设置页「文字大小」项从「文本框 + 应用按钮」改为 **− / 当前值 / +** 步进控件，按下即写入配置并同步到工作线程，序号、图标、行距同步缩放。
- 步进范围仍是 `11–18 px`，到上下限时对应按钮自动禁用（不发送消息），避免越界。
- 原 `QuickApplyFontSize`（文本输入 + Enter 应用）路径保留，方便需要精确输入的场景；输入框在折叠入口已被步进控件取代，但消息与解析逻辑仍可用。

## 内部改动

- `QuickFontFamily` 由 `Copy` 枚举（`Default` / `Mono`）重构为持有字体名 `String` 的结构体；`QuickSettings` 因此移除了 `derive(Copy)`，所有读取处改为 `.clone()`。
- 新增 `veya-desktop/src/font.rs` 的三个辅助函数：
  - `cjk_families()`：在已加载的 cosmic-text 字体库中过滤出白名单内已安装的 CJK 字族。
  - `resolve_cjk_family(value)`：规范化持久化的字体名，兼容旧版 `default` / `mono` 键。
  - `font_for_cjk_family(value)`：为指定中文字体构造 iced `Font`，未知字体回退到微软雅黑。
- 新增消息 `QuickSetFontSize(u32)`，用于步进按钮的即时写入路径。

## 升级与验证

- 下载下方 `veya-setup-0.2.10.exe` 安装即可，可直接覆盖旧版本，无需卸载。
- 这是 Windows 7 SP1 兼容构建（静态 CRT，x86_64-win7-windows-msvc）。
- 验证步骤：
  1. 打开设置 → 快捷面板，确认「字体」芯片列出系统已安装的中文字体（至少包含微软雅黑）。
  2. 点击不同字体芯片，确认快捷面板（如果同时可见）或下次唤起时字体已切换。
  3. 用 − / + 调整「文字大小」，确认每次点击即时生效、序号与行距同步缩放，到达 11 或 18 时对应按钮不再响应。
  4. 重启应用，确认所选字体与字号被保留。

# Veya v0.2.6

本版本新增记录分组、瀑布式无限滚动和浅色主题，并支持最大条数限制与自定义过期天数。快捷粘贴面板和管理历史面板均改为滚动加载，不再依赖分页按钮。

## 记录分组

- 快捷粘贴面板顶部新增分组标签行，可按分组过滤历史记录。右键菜单支持新建、重命名和删除分组。
- 分组存储在 SQLite 的 `card_group` 与 `card_group_member` 表中，固定记录加入分组后不会被自动清理移除。
- 分组过滤与搜索、类型筛选、固定筛选和时间排序可组合使用。

## 瀑布式无限滚动

- 快捷粘贴面板和管理历史面板均改为滚动至 85% 时自动加载下一页，替换原有的上一页/下一页按钮；快捷面板用方向键移到接近列表末尾时也会继续加载。
- Worker 层新增 `appending` 模式：仅页码变化时保留已有卡片并追加新结果，查询条件变化时清空重置。
- 加载下一页期间已显示的卡片保持不动，不再被“正在读取历史…”占位替换，滚动位置也不会跳回顶部。
- 在已向下滚动的列表里发生刷新（新复制、删除、固定等）时，会从顶部重新加载到当前深度，不会只剩最后一页。
- 三重防抖检查（`!has_next || loading || query_pending`）防止滚动过程中重复触发加载。
- 移除 `history_pagination()` 方法和 `PreviousHistoryPage` / `NextHistoryPage` 消息变体。

## 浅色主题

- 新增浅色主题，可在设置页切换。主题颜色统一通过 `theme.rs` 中的常量函数管理。
- 深色主题为默认，浅色主题使用独立的背景、前景、强调和状态颜色；选中的筛选标签、主按钮等强调色背景上的文字在两种主题下都保持浅色，保证可读。
- 启动时直接读取已保存的主题，选择浅色后不会先闪一下深色。

## 记录管理

- 设置页新增“保存复制项目的最大数量”：勾选后保留最新的 N 条（默认 1000），超出时自动删除最旧的记录。
- 设置页新增“粘贴条目过期时间”：勾选后超过指定天数（默认 90 天）的记录自动清理，替代原来固定的 1 / 7 / 30 天 / 永不保留期；升级时会沿用原来的选择。
- 两项设置都是“勾选框 + 数字输入框 + 应用”：输入数字不会立即生效，按 Enter 或点“应用”后才保存并清理，数值超出范围时会提示并恢复原值。
- 固定记录和已加入分组的记录不受条数限制和过期清理影响，也不计入条数。
- 两项设置的清理都按记录的创建时间排序，不依赖剪贴板序号（重启后序号会重新开始）。

## 构建与升级

- 可覆盖安装 v0.2.5，历史和设置保存在 `%APPDATA%\Veya\veya.db`；安装与卸载保留用户数据。
- 本版新增数据库表 `card_group` 和 `card_group_member`，已有数据库会自动建表，无需迁移。
- 已保存的历史记录直接适用新的分组和无限滚动方式。
